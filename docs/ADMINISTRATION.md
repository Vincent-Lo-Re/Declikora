# Administration : ce qu'on met en place une fois pour toutes

> Décidé le 27/09/2026, par QCM. C'est la référence pour construire `web/`. Quand une décision change, on la change d'abord ici.
>
> Declikora repart de zéro. Rien n'est repris de l'ancien projet (`declikora-project`) sans être redécidé ici, et on emploie des mots courants.

Les sections 1 à 9 sont **décidées**. On coche chaque ligne quand elle est en place. La section 10 regroupe ce qui est **remis à plus tard**.

## Principes

- **Des mots courants** : brouillon, publication, catégorie, chapitre, leçon, modèle, médiathèque, corbeille…
- **La base de données fait la loi.** Chaque droit (qui lit, qui modifie, qui publie) est vérifié par la base elle-même, pas seulement caché dans l'interface. Chaque règle a son test pgTAP.

## 1. Sections du menu

- [x] **Accueil** : une page simple, avec tes brouillons récents et les publications programmées. On y arrive après la connexion.
- [x] **Blog** : les articles et leurs catégories.
- [x] **Podcasts** : les épisodes (le son fait partie de l'épisode) et leurs catégories.
- [x] **Méthodes** : une méthode contient des chapitres, et chaque chapitre contient des leçons. Le chapitre a sa propre introduction en blocs, affichée avant ses leçons. Chaque leçon a son contenu en blocs.
- [x] **Pages** : les pages simples de l'app (aide, mentions légales…).
- [x] **Modèles** : les modèles de blocs (voir § 5).
- [x] **Médiathèque** : tous les fichiers (voir § 6).
- [x] **Corbeille** : une seule, pour tout ce qui a été supprimé (voir § 3).
- [x] **Équipe** et **Paramètres**, réservés aux admins. Les Paramètres contiennent les formules d'abonnement.
- [x] **Mon compte** : double vérification, déconnexion.

## 2. Équipe, connexion et sécurité

- [x] **Deux rôles** :
  - **Admin** : tout ce que fait l'éditeur, plus l'équipe (inviter, changer un rôle, retirer quelqu'un, réinitialiser sa double vérification) et les paramètres (dont les formules d'abonnement).
  - **Éditeur** : écrit, publie, dépublie et supprime les contenus ; vide la corbeille ; gère les catégories, les modèles et la médiathèque.
- [x] **Sur invitation seulement.** Un admin saisit l'e-mail et le rôle de la personne. Personne ne peut s'inscrire seul (inscriptions fermées dans Supabase). Un compte ne reçoit une fiche d'équipe que si son rôle a été posé par la clé secrète (invitation) : un compte créé autrement n'a accès à rien. Le lien d'invitation est valable 10 minutes, comme le code ; « Renvoyer l'invitation » en envoie un nouveau.
- [x] **Connexion sans mot de passe** : on tape son e-mail, puis le code à 6 chiffres reçu par e-mail (valable 10 minutes). La page affiche le même message que l'adresse fasse partie de l'équipe ou non. Limite connue : l'API de Supabase, elle, laisse deviner si une adresse a un compte.
- [x] **Double vérification obligatoire pour tous.** Après le code reçu par e-mail, on saisit le code d'une app du téléphone (Google Authenticator, 1Password…). Elle se configure à la première connexion. Tant qu'elle n'est pas faite, la base refuse tout accès aux données.
- [x] **Téléphone perdu** : un admin réinitialise la double vérification d'un autre membre (ses sessions sont aussitôt fermées). Il faut donc **toujours au moins deux admins** : la page Équipe le rappelle tant qu'il n'y en a qu'un. La base garantit qu'il reste toujours un admin **capable d'agir** (invitation acceptée et double vérification configurée). On ne change pas son propre rôle, et on ne se retire pas soi-même.
- [x] **Premier admin (une seule fois, en production)** : l'inviter depuis le tableau de bord Supabase (Authentication › Users › Invite user), puis, dans l'éditeur SQL, poser son rôle avant qu'il accepte : `update auth.users set raw_app_meta_data = coalesce(raw_app_meta_data, '{}') || '{"role":"admin"}' where email = '<son adresse>';`. Aucune adresse n'est écrite dans le dépôt.
- [x] **E-mails** (invitation, code) envoyés par **Brevo**, depuis `ne-pas-repondre@declikora.app` (domaine déjà authentifié dans Brevo : DKIM et DMARC), avec des textes en français.

## 3. Contenus et publication

- [x] **Créer** (30/09/2026) : « Nouvel article », « Nouvel épisode », « Nouvelle méthode » ou « Nouvelle page » ouvre une fenêtre : le titre (obligatoire), un point de départ s'il en existe, et les catégories (qu'on peut aussi créer sur place). Le niveau d'accès se choisit ensuite dans les réglages (« Pas encore choisi » jusque-là). L'**adresse d'une page** vient de son titre : si une autre page l'a déjà, la fenêtre le dit et bloque la création. Elle ne suit plus le titre ensuite (les liens de l'app ne cassent pas) ; elle reste modifiable dans les réglages, avec la même vérification. La liste des Pages n'a pas de colonne Adresse. « Créer » ouvre l'éditeur.
- [x] **Réglages** : la glissière « Réglages » (titre, niveau d'accès, catégories, adresse) s'ouvre dans l'éditeur, et aussi depuis le menu « … » d'une ligne des listes, avec « Enregistrer ». Si quelqu'un écrit ce contenu en ce moment, elle s'ouvre en lecture seule, avec son nom.
- [x] **Ordre des listes** (30/09/2026) : Le Fil, Radio Éclaircies et Méthodes se rangent par glisser-déposer (poignée en tête de ligne, à la souris ou au clavier) ; un contenu neuf arrive en tête. Un seul ordre, brouillons compris : l'app montre ceux qui sont en ligne dans cet ordre. Pendant une recherche ou un filtre, la liste ne se range pas.
- [x] **Brouillon, puis publication.** « Publier » envoie une copie figée dans l'app. On peut ensuite modifier le brouillon sans toucher à ce que voient les lecteurs, jusqu'à la publication suivante.
- [x] **Programmer** une publication à une date et une heure.
- [x] **Historique** des versions publiées, avec leur auteur et leur date. « Revenir à cette version » la recopie dans le brouillon.
- [x] **Retirer de l'app** (dépublier), sans supprimer le contenu.
- [x] **Supprimer** : tout ce qu'on supprime (articles, épisodes, méthodes, pages, modèles, fichiers) va dans **la corbeille**, commune à toute l'admin, avec un filtre par type. On peut l'en restaurer pendant 30 jours, puis il est effacé définitivement. S'il était publié, il disparaît aussi de l'app. L'admin et l'éditeur peuvent vider la corbeille avant la fin des 30 jours.
- [x] **Niveaux d'accès** : chaque contenu indique le niveau nécessaire pour le lire, gratuit ou une formule d'abonnement. **Il n'y a pas de niveau par défaut** : tant qu'on n'a pas choisi « Gratuit » ou une formule, « Publier » le demande, pour qu'aucun contenu ne parte gratuitement par oubli. Un admin crée, renomme et range les formules dans les Paramètres, de la moins complète à la plus complète. On en ajoute sans toucher au code.
- [x] **Accès d'une méthode** : un niveau pour toute la méthode, et on peut rendre gratuites quelques leçons, par exemple la première, pour la faire découvrir. L'**introduction d'un chapitre** est gratuite dès qu'une de ses leçons l'est ; sinon, elle suit le niveau de la méthode.
- [x] **Une méthode se publie d'un seul geste** : un seul bouton « Publier », celui de la méthode, envoie sa fiche, son plan et les chapitres et leçons modifiés. Une leçon ou un chapitre neuf reste caché de l'app tant qu'on n'a pas coché « Montrer dans l'app ». Avant de publier, l'admin montre la liste de ce qui va changer dans l'app et demande de confirmer.
- [x] **Catégories** : une liste pour le Blog, une autre pour les Podcasts, gérées par l'équipe. Un contenu peut en avoir une, plusieurs ou aucune (elles sont facultatives), et l'app s'en sert pour filtrer.
- [x] **Pour publier** un article, un épisode ou une méthode, il faut une **image de présentation** (la vignette des listes de l'app). Un épisode doit avoir son audio ; sa **transcription** est conseillée : l'éditeur avertit quand elle manque, comme pour le texte alternatif d'une image.
- [x] **Qui a fait quoi** : chaque version et chaque publication indique son auteur et sa date. Il n'y a pas de journal complet des actions.

## 4. Éditeur

- [x] Un contenu est une suite de **blocs**, qu'on ajoute, qu'on déplace par glisser-déposer et qu'on règle un par un.
- [ ] **Trois blocs au départ.** D'autres pourront s'ajouter ensuite, et l'app mobile devra savoir afficher chacun d'eux.
  - **Texte** : titres, paragraphes, listes, gras, italique, liens.
  - **Image** : l'image et son texte alternatif. **Plus de légende** (retirée le 02/10/2026) : le champ reste dans la forme des blocs, toujours vide, et l'app ne l'affiche pas. **Le texte alternatif n'est plus réclamé** (02/10/2026, [D15]) : ni avertissement sous l'image, ni dans le plan, ni sous l'image de présentation ; il se remplit toujours dans la fiche de l'image (Médiathèque) ou dans les réglages du bloc.
  - **Section** (appelée « Encadré » jusqu'au 02/10/2026) : un bloc qui contient du texte et des images, avec un fond ou une bordure. Un encadré ne contient pas d'autre encadré.
- [x] **On écrit dans l'aperçu.** Au centre, le contenu tel qu'il apparaîtra sur le téléphone. À droite, les réglages du bloc choisi. À gauche, le plan du contenu (la liste des blocs), qu'on ouvre à la demande.
- [x] **L'éditeur du Fil** (décidé le 30/09/2026 sur maquette ; les autres éditeurs gardent leur mise en page tant qu'on n'en a pas parlé). Construit en trois étapes : les colonnes, puis l'aperçu, puis les finitions.
  - [x] **Colonne de gauche toujours ouverte** (la Concentration la cache avec celle de droite), avec deux onglets jusqu'au 03/10/2026 (voir « Colonne de gauche sans onglets »). **Largeur des colonnes** (02/10/2026) : les deux colonnes ont la même largeur, prise sur ce que laisse le centre, entre 208 et 352 px. Le téléphone et ses deux barres gardent leur place (624 px avec l'Android, espaces resserrés sous 1 400 px de large) : dès 1 024 px de large, rien ne passe sous les colonnes ; trop étroit, l'aperçu défile au lieu de cacher ses barres. **Un bloc choisi dans le plan monte en haut de l'écran du téléphone.** **Plan** : la structure de l'article. **Blocs** : Texte, Image et Encadré, puis une carte **« Mes blocs »** (les mises en forme et les blocs partagés) qui fait glisser un panneau par-dessus la colonne : recherche, filtres (Tous, Mises en forme, Partagés), un aperçu de chaque bloc, une icône copie ou lien (et le nombre de contenus d'un bloc partagé), « Gérer dans Modèles de bloc ». Un clic ajoute le bloc sous le bloc choisi, ou à la fin. Pas de « derniers utilisés ».
  - [x] **Pas de barre du haut** (02/10/2026, sur maquette) : son contenu passe en tête des deux colonnes, et le téléphone gagne sa hauteur. **En tête de la colonne de gauche**, sur une ligne : la flèche de retour (« Le Fil » dans l'infobulle), le titre de l'article et l'état de l'enregistrement en icône (son nom et son heure dans l'infobulle) ; ils passent en bas de la colonne le 03/10/2026 (voir « Le bas de la colonne de gauche »). **En tête de la colonne de droite**, sur une ligne : le cadenas de la lecture seule (s'il y a lieu), l'état de publication en pastille courte (« Brouillon », « En ligne », « Modifié », « Programmé »… ; la phrase entière dans l'infobulle) et « Publier » avec ses autres actions, dont Historique (Concentration est dans la barre de l'aperçu, sous Édition et Lecture, et Historique dans le menu de « Publier », depuis le 02/10/2026). Les deux en-têtes ont la même hauteur et ne défilent pas. Ni « Ajouter un bloc » ni « Réglages » : on ajoute depuis l'onglet Blocs (voir « Ajouter un bloc, c'est l'onglet Blocs »), et tout ce qui concerne l'article est dans la colonne de droite. Les bandeaux (programmation, enregistrement arrêté, texte mis de côté) passent au-dessus du téléphone, à sa largeur. En Concentration, une pastille en haut à droite garde l'état de l'enregistrement, le cadenas et « Quitter la Concentration ».
  - [x] **Plus de résumé** (03/10/2026, après la maquette de la liste du Fil dans l'app) : un résumé de la longueur conseillée était coupé sur le téléphone dès que le texte est agrandi. Les cartes des listes de l'app montrent l'image de présentation et le titre. Le champ disparaît de l'admin **partout** : Le Fil, Radio Éclaircies, Méthodes (fiche, chapitres, leçons), dans l'aperçu comme dans les panneaux. L'admin retire le résumé d'un brouillon à l'enregistrement (`prepareDraft`). La base garde le champ, facultatif et vide (la forme des blocs ne fait que s'élargir) : `app_feed`, `app_content` et `app_method` le rendent à `null`.
  - [x] **Colonne de droite** (deux onglets jusqu'au 03/10/2026, voir « Colonne de droite sans onglets »). **Article** : « Prêt à publier ? » (le titre, l'image de présentation et le niveau d'accès, toujours visibles en haut ; chaque ligne mène à son réglage ; le titre y est depuis le 02/10/2026), la carte « Dans la liste du Fil » (on y choisit l'image de présentation ; la carte montre l'image et le titre), le niveau d'accès (une liste), les catégories (des pastilles, « Nouvelle »), puis le temps de lecture, le nombre de mots et la dernière modification. **Bloc choisi** : les réglages du bloc ; ses actions sont des icônes, leur nom dans l'infobulle, dans une barre fixe en bas (02/10/2026) : Monter, Descendre (le premier ou le dernier bloc d'une section en sort : « Monter hors de la section », depuis le 03/10/2026), puis Dupliquer et Enregistrer comme modèle… (un bloc de premier niveau qui n'est pas déjà partagé), ou pour un bloc partagé Modifier le modèle et Détacher (03/10/2026), et à l'écart, Supprimer le bloc ; mêmes icônes que le menu du plan. Choisir une section dans le plan la choisit elle, pas son premier texte. Le menu d'une ligne du plan a trois points verticaux (⋮), pour ne pas le confondre avec les « … » d'un nom coupé. Les deux colonnes ont la même marge de 16 px (en-têtes, onglets, plan, cartes). Un bloc choisi (dans l'aperçu ou le plan) ouvre ses réglages ; un clic ailleurs dans le téléphone revient à l'Article.
  - [x] **L'aperçu** : le téléphone tient dans la hauteur de la fenêtre (l'article défile dedans, à sa vraie largeur). À gauche, la barre de mise en forme, verticale. À droite, une barre verticale d'icônes : iPhone (402 × 874) ou Android (412 × 915), avec leurs logos, Édition ou Lecture (l'article comme dans l'app, sans outils), Clair ou Sombre, Grand texte (le texte grandit d'un tiers environ, comme le réglage du téléphone), et en Lecture, lire comme un abonné ou comme une personne sans la formule. **En Lecture seulement, « Écran entier »** (02/10/2026) : tout l'écran du téléphone, à ses vraies proportions, réduit pour tenir dans la hauteur de la fenêtre (le pourcentage s'affiche, 40 % au moins) ; « Ajuster » revient à l'écran à sa vraie largeur, à la hauteur de la fenêtre, la hauteur du téléphone comme limite. En Édition, l'écran reste ajusté : le réduire fausserait le glisser-déposer et le curseur. Ces choix repartent de l'iPhone, en Édition et en clair à chaque ouverture. Un bloc choisi dans le plan, ou ajouté depuis l'onglet Blocs, ramène en Édition. **Sans la formule, un article réservé ne montre pas ses blocs** : l'app ne les reçoit pas (`app_content`, `locked`) ; on voit l'image, le titre, la catégorie, le temps de lecture et l'invitation à prendre la formule. Le rendu de l'app (barre du haut, couleurs sombres, contenu réservé) reste provisoire tant que l'app mobile n'est pas dessinée.
  - [x] **Les finitions** : le plan et l'aperçu se répondent (survol, clic), l'intertitre qui ouvre un texte le nomme dans le plan, un encadré se replie, ce qui manque est signalé, un menu « … » par ligne (Dupliquer, Enregistrer comme modèle…, Sortir de la section pour un bloc d'une section, Supprimer) ; on glisse aussi un bloc de l'onglet Blocs dans l'aperçu ; **Concentration** (⌘ . ou Ctrl + .) cache les deux colonnes. Précisions : le plan ne montre que les blocs (l'image de présentation n'y est plus depuis le 02/10/2026 : elle se règle dans la colonne de droite, où « Prêt à publier ? » la signale) et compte les blocs du premier niveau (une section donne le nombre des siens, depuis le 03/10/2026) ; sont signalés une image sans fichier, un fichier qui ne s'affiche plus, un bloc partagé dont le modèle n'existe plus et une section vide (03/10/2026) ; « Enregistrer comme modèle… » ne vaut que pour un bloc de premier niveau qui n'est pas déjà partagé ; un bloc glissé tombe au premier niveau, entre deux blocs (un trait montre la place), une image ouvre aussitôt le choix du fichier ; Échap quitte la Concentration une fois les fenêtres et menus fermés. **Le plan montre le contenu, pas le type** (02/10/2026, proposition A de la maquette) : l'icône dit le type et la ligne dit le contenu ; un texte qui commence par un intertitre prend son nom (avec l'icône Texte, comme tout texte) ; ses autres intertitres n'apparaissent pas dans le plan ; une image a sa vignette, puis le nom de son fichier ; une section dit « Section avec fond » ou « Section avec bordure » (« à fond », « à bordure » jusqu'au 03/10/2026) et son nombre de blocs, ses blocs sont tenus par un trait, et une section vide montre où déposer ; un bloc partagé a l'icône de Modèles de bloc (celle du menu), sans pastille « Partagé » depuis le 03/10/2026 (« Bloc choisi » dit d'où il vient) ; ce qui manque est signalé sur la ligne (une icône depuis le 03/10/2026, voir « Le plan retouché ») ; la poignée apparaît au survol sans prendre de place au libellé, et la ligne fait place au menu ⋮ quand il apparaît (rien n'est caché dessous, depuis le 03/10/2026) ; les lecteurs d'écran gardent le nom complet (« Aller à Texte « … » »). **Pas de poignée dans l'aperçu du Fil** (02/10/2026) : c'est le plan, toujours ouvert, qui range les blocs (et « Monter », « Descendre » du bloc choisi) ; le téléphone garde le contour du bloc choisi et celui du bloc survolé, ici ou dans le plan (un seul, le plus intérieur), et reçoit toujours un bloc glissé depuis l'onglet Blocs. Les autres éditeurs gardent leurs poignées, dans la marge de l'écran (ou de l'encadré) : toujours attrapables, elles suivent le défilement d'un long bloc, et une seule s'allume ; pendant le glisser, on tient le résumé du bloc, comme dans le plan. **Le plan se range aussi par glisser-déposer** (02/10/2026) : une poignée par ligne, à la souris ou au clavier (Espace, flèches, Échap), avec les mêmes règles que l'aperçu (un encadré ne va pas dans un encadré) ; un encadré replié ne reçoit pas de bloc (il faut le déplier) ; les intertitres suivent leur texte ; rien ne bouge pendant « Choisir des blocs ».
  - [x] **Le builder relu sur un article complet** (03/10/2026) :
    - **La barre de mise en forme suit le bloc choisi** : elle montre l'état de son texte dès qu'on le choisit (aussi depuis le plan), et se grise pour une image, une section ou un bloc partagé.
    - **Un texte se résume par sa première ligne** (son intertitre, son premier paragraphe ou le premier point d'une liste), la même dans le plan et dans « Bloc choisi » ; deux paragraphes ne sont jamais collés.
    - **Une section vide** est signalée dans le plan (« Vide : n'apparaîtra pas dans l'app ») et dans « Prêt à publier ? » (« N points à vérifier dans le plan », qui choisit le premier) ; les points à vérifier n'empêchent pas de publier. Elle ne s'affiche ni en Lecture ni dans l'app.
    - **Un SVG dans un bloc Image garde sa taille réelle** (un logo n'est pas agrandi), sans dépasser la largeur, centré : dans l'aperçu, en Lecture, dans « Mes blocs » et dans l'app.
    - **« Mes blocs »** montre les images des blocs enregistrés, comme le téléphone.
    - **Un bloc partagé dans l'aperçu du Fil** n'a plus de barre au-dessus de lui (son nom est dans le plan, son liseré le distingue). Dans « Bloc choisi », deux points courts disent d'où il vient et ce que fait « Détacher » ; « Modifier le modèle » et « Détacher » sont des icônes de la barre du bas, comme les autres actions.
    - **Le haut du plan** (titre, « Choisir des blocs », nombre de blocs) reste en haut quand les lignes défilent, et la ligne du bloc choisi ailleurs vient sous les yeux.
    - **« Bloc choisi » d'une image** : sa vignette, le nom du fichier et « Ouvrir sa fiche dans la Médiathèque » (nouvel onglet).
    - **La colonne de droite réagencée** (03/10/2026, sur maquette) : les onglets « Article » et « Bloc choisi » montent dans l'en-tête (la hauteur de l'en-tête de gauche). **Une section fixe en bas de la colonne**, dans les deux onglets : le temps de lecture et le nombre de mots, la dernière modification (« Modifié à 16h31 » le jour même, sinon « Modifié le 3 oct. » ; la date complète dans l'infobulle), puis le cadenas de la lecture seule (s'il y a lieu), l'état de publication en pastille et « Publier » avec son menu ; dans « Bloc choisi », la barre d'icônes du bloc reste juste au-dessus. **« Dans la liste du Fil »** : la phrase sur l'image (« obligatoire pour publier… ») passe dans l'infobulle d'une icône Info, à droite du titre de la carte. Le résumé et sa glissière, prévus ici, ont été retirés le même jour (voir « Plus de résumé »). **Niveau d'accès** : plus de phrase orange dessous ; tant qu'il n'est pas choisi, la liste dit « Choisis un niveau », avec le « ! » orange et un bord orangé. La bordure orange de « Prêt à publier ? » est dessinée à l'intérieur de la zone : rien ne la coupe.
    - **« Prêt à publier ? » montre où agir** : un clic sur une ligne à régler amène le réglage sous les yeux, y met le curseur, et la carte visée (« Dans la liste du Fil », « Niveau d'accès », ou le champ du titre) s'allume deux fois d'une bordure orange, la couleur de l'avertissement, puis s'efface (environ 1,5 seconde). « N points à vérifier dans le plan » fait de même sur la ligne du plan. Sans animation quand l'ordinateur le demande : la bordure reste allumée le même temps, sans clignoter.
    - **Sortir d'une section** : « Monter » sur son premier bloc, « Descendre » sur son dernier, ou « Sortir de la section » dans le menu ⋮ du plan (le bloc se place juste après elle). Un bloc partagé, qui n'a qu'un bloc, n'en sort pas.
  - [x] **Ajouter un bloc, c'est l'onglet Blocs** (03/10/2026, sur maquette ; une glissière depuis le même jour, voir « Colonne de gauche sans onglets »). Partout dans l'éditeur du Fil, ajouter un bloc ouvre les Blocs, à gauche, le curseur sur le premier bloc :

    - sous le dernier bloc, le même bouton ; un clic sur un bloc de l'onglet l'ajoute sous le bloc choisi, ou à la fin ;
    - dans une section, **« Ajouter dans la section »** choisit la section et ouvre l'onglet Blocs avec un bandeau « Ajout dans la section » (× pour l'annuler) : le texte ou l'image choisi va à la fin de la section ; Section et « Mes blocs » y sont grisés ;

    - **Une section vide dans le plan** montre le même bouton « Ajouter dans la section » que dans le téléphone (plus de « Glisse un texte ou une image ici » : on ne glisse pas de bloc dans le plan depuis les Blocs ; une ligne du plan peut toujours y être glissée).

## 5. Modèles de blocs

- [x] **Trois sortes de modèles.** On choisit la sorte en créant le modèle, et il n'y a rien à choisir à l'insertion.
  - **Mise en forme** : on insère une copie déjà mise en forme, puis on y écrit son propre texte. Modifier le modèle ne change pas les contenus déjà écrits. Exemple : un encadré « À retenir ».
  - **Bloc partagé** : le même bloc, avec le même texte, dans plusieurs contenus. On le corrige une seule fois dans le modèle, et il est corrigé dans tous les brouillons qui l'utilisent. Exemple : un encadré « Contact ». Il contient **un seul bloc** : pour en regrouper plusieurs, on les met dans un Encadré.
  - **Point de départ** : un nouveau contenu s'ouvre avec une structure déjà en place, au lieu d'une page vide. Exemple : « Interview ». Il appartient à **une section**, choisie en le créant (Blog, Podcasts, leçon ou chapitre d'une Méthode, Pages) : « Nouvel épisode » ne propose que les points de départ des Podcasts.
- [x] **Quand un bloc partagé est modifié**, l'admin liste les contenus publiés qui l'utilisent et propose « Mettre à jour ces N contenus dans l'app ». Rien ne change dans l'app avant ce clic.
- [x] **Détacher** : dans un contenu, un bloc partagé peut devenir une copie ordinaire, modifiable, qui ne suit plus le modèle. Les autres contenus restent liés.
- [x] **Supprimer** : un bloc partagé ne peut pas être supprimé tant qu'il est utilisé. L'admin montre les contenus concernés, et « Détacher partout » en fait des copies ordinaires. On peut ensuite supprimer le modèle. Les deux autres sortes se suppriment librement, puisque les contenus n'en gardent que des copies.
- [x] **La liste** : un onglet « Tous les modèles » (avec le type de chaque modèle), puis un onglet par type (Mises en forme, Blocs partagés, Points de départ), avec leur nom et leur dernière modification ; « Tout sélectionner » met les modèles de l'onglet à la corbeille (un bloc partagé encore utilisé est gardé).
- [x] **Création** : dans la section Modèles de bloc, ou depuis un contenu (on sélectionne des blocs, puis « Enregistrer comme modèle »).
- [x] **Droits** : admin et éditeur.

- [x] **La fiche d'un fichier** (03/10/2026), présentée comme les colonnes de l'éditeur du Fil : en tête, l'icône du type et le nom (sans le type ni l'état) ; l'aperçu posé dans une carte ; puis des cartes avec leur icône : Description (nom, texte alternatif ou transcription), Informations (une icône par ligne ; l'accès Public, expliqué, ou Protégé), Utilisé dans (le nombre de contenus, l'icône de la section de chacun) et Remplacer ce fichier.
